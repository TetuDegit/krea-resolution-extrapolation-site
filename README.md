# Krea 14B experiment viewer

Website: https://tetudegit.github.io/krea-resolution-extrapolation-site/

Video release: https://github.com/TetuDegit/krea-resolution-extrapolation-site/releases/tag/krea14b-components-20261017

This repository contains the public website for one Krea 14B resolution extrapolation project, selected video results, and per-video summaries used by the website. It contains no source code, model weights, complete cluster logs, or files from other projects.

The site compares five fixed prompts and seeds across E0, E1, E2, E3, and E6 at 20 seconds, and pairs E1 with E6 at 50 seconds. The 35 display videos and five native E0 source videos are stored as assets of the `krea14b-components-20261017` Release. `media_checksums.tsv` records their byte lengths and SHA-256 digests.

Generated videos are research examples. The page does not establish strict noise or latent prefix identity across the earlier 20-second runs and the 50-second runs.
